# Funding and commercial opportunity inventory

Verified from first-party pages on 2026-10-19. Categories matter: a grant can fund a project, cloud credits offset usage, and commercial protocols can earn revenue only after a working integration. Listing a route does not mean an application or contract was submitted.

| Provider | Type | Verified route and fit | Source |
| --- | --- | --- | --- |
| Circle Developer Grants | Cash/USDC grant | Active Questbook portal. Agentic economic activity, liquidity and settlement are named focus areas; project needs Arc and Circle integration, roadmap, milestones. | [Circle grants](https://www.circle.com/grant), [portal](https://circle.questbook.app/) |
| Uniswap Foundation | Grant | Foundation supports protocol, tooling, research and governance; proposal includes timeline, milestones, KPI method and budget. | [Grants](https://www.uniswapfoundation.org/grants), [toolkit](https://www.uniswapfoundation.org/grantee-toolkit), [developer funding](https://developers.uniswap.org/docs/ecosystem/builder-support/get-funded) |
| Base / Coinbase | Equity investment and payment protocol | Base Ecosystem Fund publishes an application for pre-seed and seed investments. Coinbase's x402 is a payment protocol, not a grant application route. Coinbase's 2025 summer builder grants are closed. | [Base fund](https://www.base.org/ecosystem-fund), [application](https://www.base.org/ecosystem-fund/apply), [x402](https://www.coinbase.com/developer-platform/discover/launches/x402), [closed 2025 round](https://www.coinbase.com/developer-platform/discover/launches/summer-grants-2025) |
| Robinhood Chain | Sponsored buildathon | Robinhood committed $1m to Arbitrum Open House 2026 to support Robinhood Chain developers. This is a program allocation, not a standing Robinhood grant intake. | [Robinhood announcement](https://robinhood.com/newsroom/robinhood-chain-launches-public-testnet/), [chain docs](https://docs.robinhood.com/chain/) |
| Virtuals EconomyOS | Compute/inference credits | GitHub connected agent builders can seek weekly credits; official discretionary form exists. Credits route to EconomyOS, not a cash wallet. | [Virtuals community](https://os.virtuals.io/community), [builder review form](https://virtualsprotocol.typeform.com/to/BwtdGEAL) |
| 1inch Fusion | Commercial resolver opportunity | Self-service Business Portal registration and onchain contract verification for Fusion/Fusion+ resolver participation. This is potential operating revenue, not grant funding. | [resolver guide](https://business.1inch.com/portal/documentation/resolvers/introduction), [self-service](https://business.1inch.com/whats-new/resolver-self-service-onboarding) |
| AWS Activate | Cloud credits | Eligible startups can apply for up to $200k of AWS credits; AWS also documents an agent-assisted application path. Builder ID, startup profile and AWS account are required. | [AWS credits](https://aws.amazon.com/startups/credits), [agent path](https://aws.amazon.com/aws-startups/credits/apply-using-your-ai-agent/) |
| Google for Startups Cloud | Cloud credits | Pre-funded MVP tier and funded startup tiers; Google lists up to $350k for eligible AI startups. Application requires a Cloud billing account. | [program](https://cloud.google.com/startup), [onboarding](https://cloud.google.com/startup/onboarding) |
| Microsoft for Startups | Azure credits and support | Software product startups apply through startups.microsoft.com. Microsoft lists company, stage and location eligibility and an investor code as optional for extra benefits. | [overview](https://learn.microsoft.com/en-us/startups/overview), [application process](https://learn.microsoft.com/en-us/startups/microsoft-for-startups/application) |
| Cloudflare for Startups | Infrastructure credits | Startup benefits offset eligible Cloudflare usage; tier and eligibility depend on company stage. | [program](https://www.cloudflare.com/startups/) |
| NVIDIA Inception | Startup benefits | Free startup program with technical support and partner benefits; no cash grant is promised. | [program](https://www.nvidia.com/en-us/startups/) |
| Alchemy Solana Fund | Infrastructure credits | Eligible Solana builders may receive infrastructure credits rather than cash. | [program](https://www.alchemy.com/solana-20m-fund) |
| NLnet | Open-source grant | Current calls fund open-source public goods. NLnet explicitly requires disclosure of AI use and says it is not interested in AI-generated projects or proposals, so an autonomous generated application is a poor fit. | [apply](https://nlnet.nl/propose/) |

Prioritize Circle and Uniswap for direct grant proposals tied to a deployed product; Base for equity investment; Virtuals, AWS, Google and Microsoft for infrastructure credits; and 1inch for commercial resolver onboarding. Recheck each live intake and eligibility at execution time, and preserve its receipt or transaction hash in submission history.
