Install SuperCraftOS

For iPhone and iPad running iOS 17 or later. This free-account build needs SideStore to sign it for your device.

1. Set up SideStore

Open the SideInstaller setup site and follow its profile and installation steps. Return here when SideStore opens on this device. SideInstaller is a separate third-party project and its certificate may be rejected by iOS.

Open SideInstaller setup

If that route fails, use SideStore's official setup; it requires a computer once and LocalDevVPN.

2. Install SuperCraftOS

Checking the current device build.

What happens after tapping Install

SideStore downloads the IPA, asks for Apple Account access if needed, signs it for this device, and starts installation. Confirm any iOS prompts. Return to SideStore to see the result; this web page cannot read it.

Being signed in to iCloud does not grant a website code-signing access. No Apple password or device profile is requested by this page. Free personal provisioning expires after seven days and needs refresh.
