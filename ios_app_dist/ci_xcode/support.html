SuperCraftOS Support

SuperCraftOS iOS app, version 1.0 (1)

SuperCraftOS is a control surface for an agent system that you run. The app connects to your own SuperCraftOS control center. Everything it shows comes from that server.

First run

  1. Open the app. It is already pointed at your control center.
  2. If you run the control center somewhere else, open Connection, enter the address, and tap Save and connect.
  3. Your address is saved as a bookmark, so you can switch between a public host and one on your local network with one tap.

The app shows no data

  • Check the backend address in Connection.
  • Check that the control center is running and reachable over https.
  • A http address is only accepted for the local network, by design. A public address must be https.

Adding the custom keyboard

  1. Settings > General > Keyboard > Keyboards > Add New Keyboard > SuperCraftOS.
  2. Switch to it with the globe key.
  3. Turn on Allow Full Access. Apple requires it for any keyboard that uses the network, and the keyboard talks to your own agent.

The keyboard says the backend is not configured

The keyboard's backend address is fixed when the app is built. Connect the app first, and if you need a different address, rebuild the app with SUPERCRAFTOS_BACKEND_URL set to it.

Privacy

See the privacy policy. The app collects no data and sends everything only to the server you configured.

Getting help

Include the app version, your device model, and the address of your control center if the problem is a connection problem. The full source and the build and release instructions are in the project repository.
