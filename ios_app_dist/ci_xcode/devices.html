SuperCraftOS

Device setup · one Apple account per device · free, no payment

Two accounts, one device each, and never the same account twice. A free Apple account may register only 10 App IDs per 7 days and install only 3 apps per device. SideStore, SuperCraftOS and the keyboard extension are three separate registrations. Splitting the two devices across your two accounts means neither account comes close to the cap, and their 7 day clocks run in parallel so the app is never broken on both at once.
The one thing that cannot be avoided. A free Apple account has no access to Certificates, Identifiers and Profiles in the developer portal, so you cannot add your device there yourself. The device registers itself, automatically, during the signing session. That session needs the device plugged into a computer once, through USB. After that it is all wireless, for the life of the app.

One, on a computer

iloader is the official tool for this. It is open source, it registers the device for you, it installs SideStore, and it places the pairing file. It runs on Windows, Linux and macOS.

Windows · iloader (.exe) Linux · iloader (.deb) macOS · iloader (.dmg) iloader.app, the official site

On Linux you also need usbmuxd. On Windows you need iTunes from Apple, not the Microsoft Store version.

Device A · the iPad

APPLE ID A the iPad
  1. Plug the iPad into the computer with USB. Tap Trust on the iPad.
  2. Open iloader, sign in with Apple ID A, select the iPad, and choose Install SideStore. It registers the device and the App ID for you.

    On iOS 26.4 and later pick the nightly option.

  3. On the iPad, install LocalDevVPN from the App Store and connect it.
  4. Settings → General → VPN & Device Management → [Apple ID A] → Trust

    Be on cellular data. iOS calls Apple to verify the certificate.

  5. Settings → Privacy & Security → Developer Mode → on Restart, then confirm Turn On.
  6. Open SideStore, sign in with Apple ID A, tap the 7 DAYS counter once.
  7. In SideStore tap + and install the app. 1 APP ID
  8. When you want the keyboard, install app + keyboard instead. 2 APP IDS

    Do the app first, so you have a working install before you spend a second App ID on the extension.

  9. Open the app, Connection → https://agent.commetai.ca
  10. Settings → General → Keyboard → Add New Keyboard → SuperCraftOS, globe to switch, Allow Full Access on.

Device B · the iPhone

APPLE ID B the iPhone
  1. Plug the iPhone into the computer with USB. Tap Trust on the iPhone.
  2. Open iloader, sign in with Apple ID B, select the iPhone, and choose Install SideStore.
  3. On the iPhone, install LocalDevVPN from the App Store and connect it.
  4. Settings → General → VPN & Device Management → [Apple ID B] → Trust
  5. Settings → Privacy & Security → Developer Mode → on Restart, then confirm Turn On.
  6. Open SideStore, sign in with Apple ID B, tap the 7 DAYS counter once.
  7. In SideStore tap + and install the app. 1 APP ID
  8. When you want the keyboard, install app + keyboard instead.
  9. Open the app, Connection → https://agent.commetai.ca
  10. Settings → General → Keyboard → Add New Keyboard → SuperCraftOS, globe to switch, Allow Full Access on.

Each device holds 2 apps, or 3 with the keyboard, which is the limit of 3 per device. If an install fails, you have burned an App ID. If you hit the cap, wait 7 days or switch to the other account.

After the first install

Nothing. SideStore re-signs the app in the background over Wi-Fi every 7 days. Keep LocalDevVPN connected when you are on Wi-Fi, and you never touch a cable again.

The iPad, if you would rather not do any of that

NO SIGNING AT ALL Swift Playgrounds

No Apple account, no USB, no App IDs, no Developer Mode, no expiry. The app only, no keyboard.

  1. Install Swift Playgrounds from the App Store.
  2. Open the Playgrounds bundle in Safari, save it to Files.
  3. Files → tap the zip → Open with → Swift Playgrounds → Run.
  4. In the app, Connection → https://agent.commetai.ca
